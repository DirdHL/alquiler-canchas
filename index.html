Configuración de Supabase (Base de Datos en la Nube)

Al conectar Supabase, tus reservas se guardarán en la nube. Esto permitirá que tus compañeras vean y modifiquen las reservas en tiempo real desde sus propias computadoras o celulares.

Ve a Configuración → Claves API y copia la clave anon | public de la pestaña Legacy

Pasos para Crear la Tabla en Supabase

  1. Entra a tu panel de Supabase y crea un proyecto gratuito.
  2. Ve a Configuración → Claves API y copia la clave anon | public de la pestaña Legacy. ⚠️ NO copies la clave secreta (service_role).
  3. Ve al Editor SQL en el menú lateral izquierdo.
  4. Haz clic en Nueva consulta, pega el siguiente SQL y presiona Ejecutar:
CREATE TABLE IF NOT EXISTS reservas (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  name TEXT NOT NULL,
  dni TEXT NOT NULL,
  phone TEXT,
  court TEXT NOT NULL,
  sport TEXT NOT NULL,
  date DATE NOT NULL,
  start_time TIME NOT NULL,
  end_time TIME NOT NULL,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Habilitar Row Level Security (necesario para Publishable key)
ALTER TABLE reservas ENABLE ROW LEVEL SECURITY;

-- Permitir acceso publico (leer, insertar, actualizar, eliminar)
CREATE POLICY "Acceso publico" ON reservas FOR ALL USING (true) WITH CHECK (true);

-- Habilitar acceso en tiempo real
ALTER PUBLICATION supabase_realtime ADD TABLE reservas;
